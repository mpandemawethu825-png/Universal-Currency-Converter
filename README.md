Status: Production-ReadyAn ultra-modern, mobile-first, and high-precision Universal Currency Converter built with dynamic real-time exchange rates, financial-grade arithmetic, historical charting, and Google-inspired glassmorphism UI.Created by Mawethu Mpande @ SISONKE HUBKey FeaturesDynamic Multi-Provider Rate Engine:Primary API: Frankfurter API (European Central Bank published reference rates).Secondary API Fallback: Open ER API for high availability.Crypto Data Feed: CoinGecko API for live cryptocurrency pricing (BTC, ETH, SOL).Financial Precision Math: Powered by Decimal.js to eliminate floating-point precision errors during cross-rate arithmetic and fee adjustments.ZAR & All-World Currency Support: Optimized with South African Rand (ZAR) defaults, quick-pair chips (USD/ZAR, GBP/ZAR, EUR/ZAR, ZAR/BTC), and a searchable modal with Fiat & Crypto filters.Interactive Historical Trends: Built with Chart.js to visualize historical rate trends across custom timeframes (7D, 30D, 90D, 1Y).Google-Inspired Glassmorphism Design: Restrained Google brand palette (#4285F4, #EA4335, #FBBC05, #34A853), soft blur cards, dark/light theme toggle, and responsive touch controls.Offline Resilience & Caching: Automatic local storage caching with explicit stale-data indicator and offline conversion access.Spread Fee Calculator: Configurable bank/remittance percentage markup slider and net conversion preview.Architecture & TechnologiesFrontend: HTML5, CSS3 (Tailwind CSS CDN), Vanilla JavaScript (ES6+).Icons: Lucide Icons.Charts: Chart.js.Math Library: Decimal.js.Deployment: Standalone single-file bundle (index.html) executable directly in any web browser without build tools.Quick StartOption 1: Direct File AccessSimply double-click or open index.html in modern desktop or mobile web browsers (Chrome, Edge, Firefox, Safari, Samsung Internet).Option 2: Local Web ServerFor testing or production hosting, serve the directory via any HTTP server:# Using Python 3
python3 -m http.server 8000

# Using Node.js npx http-server
npx http-server . -p 8000
Then visit http://localhost:8000 in your web browser.How the Exchange Engine WorksInitialization: On application load, the engine initiates HTTPS requests to the primary Frankfurter API endpoint (/latest?from=USD).Fallback Strategy: If Frankfurter API fails or times out, the app silently fails over to Open ER API.Crypto Hydration: Crypto market rates are fetched in parallel from CoinGecko's simple price API and normalized into the internal rates object.Cross-Rate Formula:
$$\text{Converted Amount} = \text{Source Amount} \times \left( \frac{\text{Target Rate (USD Base)}}{\text{Source Rate (USD Base)}} \right) \times \left( 1 - \frac{\text{Fee \%}}{100} \right)$$Caching: Verified rate payloads are cached to localStorage with timestamps to allow full functionality when offline.Supported Currencies & ProvidersCategoryCurrenciesPrimary SourceMajor FiatUSD, EUR, GBP, ZAR, JPY, AUD, CAD, CHF, CNY, INR, BRL, NZD, SGD, HKD, SEK, NOK, MXN, AED, TRY, KRW, PLN, ILSEuropean Central Bank via Frankfurter APICryptocurrenciesBTC (Bitcoin), ETH (Ethereum), SOL (Solana)CoinGecko Market AggregatorLicense & AttributionDesigned and developed by Mawethu Mpande for SISONKE HUB.
